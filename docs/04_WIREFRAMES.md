## Responsive and Accessibility

- camera 화면은 SafeArea, sensor orientation, system gesture inset을 반영한다.
- landscape/tablet은 preview 2/3, metrics 1/3 레이아웃을 사용한다.
- counter는 text scaling에도 잘리지 않으며 상태를 색만으로 전달하지 않는다.
- PosePainter는 screen reader에서 장식 요소로 제외하고 상태 문구에 semantic label을 준다.
